# Pharma Lab Global Italy — Research Education

Static educational website for five peptide research topics. Research and laboratory use only; not for human or animal use or consumption.

## Publishing
Upload all root files to the `main` branch of `italypharmalabglobal/italypharmalabglobal.github.io`. In Settings > Pages select `Deploy from a branch` / `main` / `/(root)`.

## Adding future posts
Use a dedicated `/blog/` folder with a separate listing or Jekyll posts. Do not upload the ZIP itself: extract and upload the individual files.
